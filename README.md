# TEAMUP

> Teamup est un site web dédié à la communauté League of Legends, permettant aux joueurs de trouver des coéquipiers et aux équipes de recruter de nouveaux joueurs.

## 📋 Présentation

Teamup permet aux joueurs et aux équipes de créer des annonces présentant leur profil et leurs recherches. Le site aide les joueurs de League of Legends à trouver des coéquipiers et à rejoindre ou créer une équipe.

## ✨ Fonctionnalités

* Créer un compte
* Se connecter
* Se déconnecter
* Créer une annonce de joueur
* Créer une annonce d'équipe
* Modifier ses annonces
* Supprimer ses annonces
* Afficher les annonces de joueurs
* Afficher les annonces d'équipes
* Filtrer les annonces par pseudo, rôle, rang, champion, etc.
* Gestion des utilisateurs

## 🛠️ Technologies utilisées

* HTML / CSS
* PHP
* JavaScript
